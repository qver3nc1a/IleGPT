# IleGPT
Building a GPT-style language model (following Sebastian Raschka's Build a Large Language Model (From Scratch)).
Implemented, pre-trained and fine-tuned using PyTorch.

## Progress
🔸 Tokenizer
🔸 Data Loader
🔸 Embeddings
🔸 Self-Attention
🔸 Multi-Head Attention
🔸 Transformer Block
🔸 GPT Model
🔸 Training
🔸 Fine-tuning
🔸 Text Generation
